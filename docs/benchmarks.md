# Benchmarks

Every number here is regenerated by `benchmarks/level0_physics.py`,
`benchmarks/device_model_3d.py` or `benchmarks/device_model_cad.py` per the
ecosystem benchmark standard (warm-up, repeated samples, percentiles, one
row per backend, provenance in the artefact). The operation is one pass
over a synthetic parameter grid evaluating, per point, the cylindrical
Taylor eigenvalue, the formation disposition and the relaxed-state field
at five radial by five axial stations (twenty-five samples); the time is
reported per grid point and includes the Python call overhead of both
backends (the native backend is called per sample through its bindings,
so this measures the call-through cost of the kernels, not a vectorised
scan). Both backends evaluate the Bessel functions and the unit circle
through the pinned shared kernel library (ADR 0006). Nothing here is a
physics claim.

## Regenerate

```bash
make rust
VIRTUAL_ENV=.venv PATH=.venv/bin:$PATH maturin develop --release -m rust/Cargo.toml
# the 3D-model benchmark needs the pinned library's native module; build it
# from the library checkout at the manifest's kernel_library.source_commit:
VIRTUAL_ENV=.venv PATH=.venv/bin:$PATH maturin develop --release -m <scpn-reactor-kernels>/rust/Cargo.toml
.venv/bin/python benchmarks/level0_physics.py --points 20000 --warmup 3 --repeats 20 --label local
.venv/bin/python benchmarks/device_model_3d.py --segments 4096 --warmup 3 --repeats 20 --label local
# the CAD benchmark needs the pinned library's `cad` extra (installed by
# the optional `cad` extra of this package):
.venv/bin/python benchmarks/device_model_cad.py --warmup 2 --repeats 10 --label local
```
